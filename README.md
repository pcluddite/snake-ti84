# SNAKE for TI-84
Simple snake program for TI-84 calculator

## Controls
* Arrow keys to move
* Enter to pause/resume

## Known issues
* You can only enter letters on the high score list. Anything else will default to 'A'
* Slows down as the snake gets bigger (this can be mitigated by turning off features such as MathPrint)
* You can reverse direction and immediately kill the snake.
